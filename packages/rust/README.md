# @ctx-traits/rust

Dual-use package: authoring-time re-exports of the Rust-specialized worker/
reviewer role builders and `cargoFixLoop` from `@ctx-traits/toolkit`, and the
vendorable canonical trait packages `.ctx/traits/rust` and
`.ctx/traits/cargo-fix` for `ctx traits sync`.

## Install

```sh
pnpm add -D @ctx-traits/rust
```

## Source

https://github.com/ctx-company/traits (`packages/rust`).
